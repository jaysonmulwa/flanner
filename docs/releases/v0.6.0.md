# flanner 0.6.0 — Linear integration

Link plan files to their Linear issues so a plan and its ticket travel together,
in the CLI, over MCP, and in the web dashboard.

## Added
- **`flanner linear` CLI group and MCP tools.** Link a plan to a Linear issue
  (`ENG-123`), list and show links, unlink, and configure the workspace.
- **Two tiers.** Link-only by default (stores the id, builds the `linear.app`
  URL, no credentials). With `LINEAR_API_KEY` set, `link` verifies the issue
  exists and caches its title and state, `--attach-url` attaches a URL to the
  issue, and `flanner linear refresh` re-pulls live status. The GraphQL client
  uses the standard library, so it adds no runtime dependency.
- **`flanner linear auth`** validates the key against Linear and prints the MCP
  server config snippet (with `LINEAR_API_KEY` in its `env`) so the agent's
  server process gets the same access it does not inherit from your terminal.
- **Web UI.** The plan viewer shows a "Linked Linear issues" panel (id, cached
  state, title, link); the project page marks linked plans with a `Linear ×N`
  badge.

The API key is read from the environment only: never stored on disk, never a
CLI flag, never logged. See [docs/LINEAR_INTEGRATION.md](../LINEAR_INTEGRATION.md).
