# flanner 0.5.0 — MCP packaging

This release makes flanner easier to register as an MCP server and prepares it
for the MCP registry.

## Added
- **`flanner-mcp` console script** to run the MCP server, equivalent to
  `python -m flanner.server`. Cleaner to reference in client configs and
  registry listings.
- **`server.json` manifest** for submitting flanner to the
  [MCP registry](https://registry.modelcontextprotocol.io).

## Changed
- **`flanner init` and `flanner start` now emit an absolute interpreter path**
  (`sys.executable -m flanner.server`) instead of a bare command. The client
  app spawns the server regardless of its PATH, so venv and pipx installs work
  even though their Scripts/bin directory is not on the GUI app's PATH.

## Upgrade
```bash
pip install --upgrade flanner
flanner init   # re-run to refresh the MCP registration with the new config
```
Existing registrations keep working; re-running `flanner init` updates them to
the PATH-independent form.
