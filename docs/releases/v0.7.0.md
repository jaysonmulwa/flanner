# flanner 0.7.0

A big release: a real web editor, reading customization, self-adoption for new
projects, subdirectory plans, and a batch of dogfooding fixes.

## Added
- **Web editor.** The plan editor is now CodeMirror (vendored, no build step,
  offline): line numbers, markdown syntax highlighting, active-line, and list
  continuation, themed to the light/dark palette. It enhances the existing
  textarea, so editing still works with JavaScript disabled.
- **Reading customization.** An "Aa" popover on the plan viewer sets a preset
  (Default / Book / Night / Plain), font, size, and width. Presentation-only and
  client-side (persisted to localStorage), so the server keeps caching one
  canonical HTML.
- **Self-adoption.** `flanner setup` (one-time, global) registers the MCP server
  for Claude Desktop and Claude Code (user scope) and adds a narrow nudge to
  `~/.claude/CLAUDE.md`, so Claude offers to adopt a repo when you write a plan
  doc in a project that is not yet flanner-managed. A new `initialize_project_tool`
  lets the agent adopt a repo itself, without leaving the chat.
- **Subdirectory plans.** A plan name may be a subpath
  (`auth/login-flow` -> `.plans/auth/login-flow_v1.md`); parent directories are
  created, `sync` finds nested plans, and path traversal is rejected.

## Changed
- Static assets are version-stamped so an upgrade busts the browser cache.
- `flanner web` fails gracefully when the port is taken, with an actionable
  message, and `--open-browser` waits for the server to be ready.

## Fixed
- Editing a plan in the web UI no longer corrupts its line endings (CRLF was
  being doubled on Windows and degrading the file on every save).
- `flanner init` now also registers with **Claude Code** (project `.mcp.json`),
  not only Claude Desktop, so CLI users see the flanner tools under `/mcp`.

## Upgrade
```bash
pip install --upgrade flanner
flanner setup   # optional: make flanner offer to adopt new projects globally
```
